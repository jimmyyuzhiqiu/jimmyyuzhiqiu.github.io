咔得乐在本项目中按“非电控实体建构材料”设计。

- 电控；
- 传感器；
- 编程；
- 自动驾驶；

# 五、老师不能只看到原则，要看到真实话术

必须提供话术库。

例如：

学生问：
“老师到底怎么搭才对？”

教师：
“今天没有标准模型。先告诉我，你们现在想解决的是哪个问题？”

学生模型很漂亮但没有功能逻辑：
“先不要告诉我它像什么。告诉我这三个区域分别解决什么问题。”

学生只解释、不愿拆改：
“解释不能代替修改。现在请在模型上留下一个看得见的版本变化。”

学生照抄EvoMind：
“这是AI的建议，不是你们的决定。你们接受哪条、拒绝哪条？为什么？”

至少形成覆盖以下场景的教师话术：
任务发布、知识追问、学生卡住、学生抢搭、方案冲突、零件不足、AI照抄、模型过度装饰、拒绝修改、时间落后、答辩追问。

# 七、EvoMind定位

前台原则上只有一个入口：

1. 知识核验；
2. 设计追问；
3. 情境挑战；
4. 档案/答辩整理。

AI永远在学生思考之后：

学生先猜 → 学生形成问题 → 老师/EvoMind核验和追问 → 学生决定 → 实体模型验证。

- 给唯一正确布局；
- 虚构咔得乐能力；

- 直接把AI生成图当成实体成果。

# 三天18小时核心课程总纲

## 总驱动问题
怎样为4名科研人员设计一座能够在月球南极长期开展工作的科研基地？

## 总体学习闭环

问题 → 科学依据 → 设计决策 → 草图 → 静态实体模型 → 人工情境验证 → 发现冲突 → 拆改 → 新版本 → 证据表达。

## 六个半日

| 半日 | 核心任务 | 主要成果 |
|---|---|---|
| Day1 AM | 看懂月球问题、选址、需求、总体规划 | 选址矩阵 + 功能需求 + 总体草图V0 |
| Day1 PM | 把总体规划第一次变成实体模型 | V1 → 路线/冲突验证 → V2 |
| Day2 AM | 4人真实住进去需要什么空间 | 功能模块草图 + 至少3个静态模块 |
| Day2 PM | 把模块连成可使用的空间系统 | 4条动线 + 模块调整 + V2.5 |
| Day3 AM | 条件变化后还能工作吗 | 两轮情境挑战 + V3 |
| Day3 PM | 用证据证明设计并答辩 | 版本证据链 + 项目展板 + 总工答辩 |

## 三天结束每组必须留下

- 选址评分矩阵；
- A3总体规划草图；
- V1/V2/V2.5/V3照片或清楚的版本记录；
- 至少4条路线/情境验证记录；
- 至少2次明显实体修改；
- 至少3条经教师审核的科学/设计依据；
- 至少1条AI建议被修改或拒绝并写理由；
- 一张项目展板；
- 2分钟最终答辩。

## 三天进度原则

不要要求Day1就搭出精美基地。

Day1：先建立总体逻辑。
Day2：加入功能和使用关系。
Day3：用变化条件逼迫方案成熟。

“越搭越漂亮”不是课程主线，“每一次修改越来越有理由”才是主线。

# 教师课堂话术库

## 学生问“怎么搭才对？”
“今天没有标准模型。先告诉我，你现在想解决哪个问题？”

## 学生一拿积木就开始堆
“积木先放回材料区。给我看你们的三项设计重点，能说清楚再开始。”

## 模型很漂亮但不知道用途
“先不要告诉我它像什么。告诉我这三个区域分别解决什么问题。”

## 学生说“AI说这样最好”
“AI给的是建议，不是决定。你们用什么证据决定接受？”

## 学生照抄AI
“请找出AI建议中一条你们不完全同意的地方。”

## 学生不愿拆
“解释不能代替修改。请在模型上留下一个能看见的版本变化。”

## 学生说“拆了不好看”
“今天评分不看漂亮不漂亮。我们看修改有没有理由。”

## 两个同学争执
“每个人先说自己的设计目标，不说‘我喜欢’。哪一个方案更能满足任务？”

## 零件不够
“先判断这是功能缺失，还是只是外观没有零件。功能可以用标签占位，但必须注明概念功能。”

## 学生做出不存在的高科技功能
“这个想法可以写在未来升级区，但今天模型只能表达我们真实拥有的材料能力。”

## 时间落后
“现在停止装饰。每组只保留：核心功能、一次验证、一次修改和版本说明。”

## 学生不会答辩
“不要介绍所有模块。只讲：我们原来怎么想、哪里出了问题、最后为什么改。”

## 模型在验证中倒了
“先不要急着重搭。请记录：什么动作让它倒了？这是结构问题还是使用情境问题？”

# 课堂异常SOP V3

## 时间落后20分钟
立即停止装饰。保留：核心模型、一次验证、一次修改、版本记录。

## 时间落后40分钟以上
减少路线数量/展示组数，不删除“发现问题→修改”。

## 零件不够
先检查是否真的影响功能。如果只是无法表示某个概念，可用纸质功能标签占位并写“概念功能”。禁止AI凭空补零件。

## 学生只想抄示例
示例只作为结构/表达参考，教师遮掉整体布局，要求小组先说自己的任务约束。

## 学生不会搭
教师可演示“连接动作”，不能搭出完整模块答案。

## AI不可用/网络断开
切换：纸质知识卡、教师追问卡、Challenge预印卡、学生执行表。课程不依赖AI才能继续。

## AI幻觉产品能力
固定回复：
“该建议涉及当前咔得乐未确认能力，本课不采用。请改写为仅通过静态模型、空间布局、纸卡或人工情境模拟可以验证的版本。”

## 学生组内严重分歧
每个方案必须先说目标/证据。用任务约束投票，不用“谁声音大”。

## 学生提前搭完
不给更多装饰任务。追加路线冲突/扩建/Challenge检查。
