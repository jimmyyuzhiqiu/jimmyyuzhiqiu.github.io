# 云知师AI教师版 Remotion 半成品制作包 V2

> **最高优先级：先执行 `ART_DIRECTION_LOCK_V2.md`、`design_tokens.json` 与 `ART_DIRECTION_QA.json`。**
> 如果 V1 文档与 V2 Art Direction 冲突，以 V2 为准。

## V2目标
V1 已经解决“讲什么、剪什么”；V2 重点解决“怎么做得好看”。

最终成片必须具备：
- 成熟 AI SaaS 产品发布片的视觉质感；
- 清晰的主视觉；
- 足够大的产品 UI 与成果；
- 足够大的数字人；
- 连续的视觉叙事；
- 极简、克制、教育科技感。

## 执行前必读
1. `ART_DIRECTION_LOCK_V2.md`
2. `design_tokens.json`
3. `ART_DIRECTION_QA.json`
4. `参考构图/REFERENCE_01_数字人讲解.svg`
5. `参考构图/REFERENCE_02_电脑Demo.svg`
6. `参考构图/REFERENCE_03_成果全屏.svg`
7. `参考构图/REFERENCE_04_品牌片尾.svg`
8. `参考构图/REFERENCE_05_课前课中课后闭环.svg`

## 关键要求
- 先按参考构图的**比例、留白、层级和主视觉大小**搭版，再替换真实内容。
- 不允许自由发挥成“多个卡片 + 小电脑 + 小数字人”的模板布局。
- 重要成果优先全屏，不要为了统一而全部塞进电脑。
- 一屏一个重点，克制比堆信息更重要。

## 视觉硬指标
- 数字人主讲：可见高度 70%–78%
- Demo数字人：可见高度 >=65%
- Demo电脑：可见宽度 68%–74%
- PPT/报告/图片/互动网页：85%–95% 大画幅
- 同屏同款圆角卡：最多2张
- 核心文字：>=26px
- Caption：<=2行，最长18个中文字

## Review Gate
Review URL 前必须 Render Still：S01 / S02 / S04 / S05 / S07 / S10 / S12。
全部通过 `ART_DIRECTION_QA.json` 后才能进入 Review。

## 产品故事不变
云知师AI教师版不是“功能大全”，核心主线仍是：
课前减负 → 课中即时支持 → 课后分析 → 数据回流 → 教研共享。

如果成片视觉很满、很碎、像PPT，哪怕功能都正确，也判定为 FAIL。
